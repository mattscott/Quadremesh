# Test corpus

Shared input meshes used by every phase's acceptance tests. Assembled in **P1**:

- `sphere` — smooth, closed; expected topological singularities only.
- `torus` — genus-1; expected ~0 field singularities.
- `cylinder` — open boundaries.
- `head` — scanned organic surface.
- `hard-surface` — mechanical part with sharp creases (feature-mode target).
- `non-manifold` — deliberately dirty input (must load without throwing; degrade best-effort).

Golden reference outputs (from the [reference oracle](../../tools/reference-oracle)) live under
`tests/golden/` and are committed; they are regenerated by an explicit script, not on every CI run.
